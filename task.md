# ТЗ: AI-удаление мебели/хлама с фото помещений (mask-based inpainting) для агентов/брокеров

## 1) Цель и краткое описание
Сделать веб-инструмент для агентов и брокеров недвижимости: пользователь загружает фото помещения, **кистью отмечает мебель/хлам**, сервис отправляет **фото + маску** в **OpenAI Images Edit** и возвращает **улучшенную версию “пустое помещение”** (качество “норм для объявления”).

Ключевые свойства MVP:
- **1 фото → 1 результат**
- **пользователь сам рисует маску**
- внешний AI-API допустим
- фокус на скорости запуска и простоте UX

## 2) Пользователи и сценарии
**ЦА:** агенты и брокеры (жилой/коммерческой недвижимости).

### Основной user story
1. Пользователь открывает сайт
2. Загружает фото
3. Кистью “стирает” мебель (на маске)
4. Нажимает “Сгенерировать”
5. Получает результат, сравнивает “до/после”, скачивает обработанное фото

## 3) Область работ (Scope)
### In scope (в MVP)
- Upload изображения (JPG/PNG)
- Редактор маски (кисть/ластик, размер кисти, Undo)
- Генерация результата через OpenAI **POST /v1/images/edits**
- Показ результата + скачивание PNG/JPEG
- Мини-логирование запросов и ошибок
- Базовая защита API (ключ только на сервере, rate limit)

### Out of scope (позже)
- Пакетная обработка (batch)
- Аккаунты/оплата/лимиты по тарифам
- История проектов
- Авто-сегментация мебели без маски
- “Виртуальный ремонт/стейджинг” (другая фича)

## 4) Требования к качеству результата
- “Норм для объявления”: без грубых артефактов, с сохранением перспективы и света
- Не обязано быть “3D-виз”
- Допускается минимальная перерисовка вне маски (модель иногда “чуть трогает” всё изображение) — нужно снижать эффект настройками + промптом

## 5) UX / UI требования

### Экран A: Загрузка
- CTA: “Загрузить фото”
- Поддержка drag&drop
- Ограничение размера файла (например ≤ 20MB на фронте)
- После загрузки → переход в редактор

### Экран B: Редактор маски
- Два слоя: 
  - слой фото (read-only)
  - слой маски (рисуем)
- Инструменты:
  - Brush size slider (например 5–80 px)
  - Mode toggle: “Удалять (прозрачность)” / “Вернуть (белым)”
  - Undo (минимум 10 шагов)
  - Reset
- Визуализация маски: полупрозрачный оверлей (например красный), но экспортировать надо PNG с альфой (см. ниже)
- Подсказки пользователю:
  - “Закрашивай мебель с небольшим запасом”
  - “Не оставляй дырок внутри объекта”
  - “Лучше крупные мазки”

### Экран C: Результат
- Блок сравнения: “До / После” (slider или две карточки)
- Кнопки:
  - “Скачать результат”
  - “Обработать ещё фото”
- Сообщения об ошибках (человечные)

## 6) Маска: строгие технические требования
Используем маску как “трафарет”:
- **Прозрачные области (alpha = 0)** = где разрешено редактирование (там “убираем мебель”)
- Непрозрачные области = оставляем как есть

Требования OpenAI Images Edit:
- `mask` — **валидный PNG**, **с теми же размерами, что и image**, и **< 4MB**. :contentReference[oaicite:0]{index=0}
- “Полностью прозрачные области маски указывают, где image должна быть отредактирована”. :contentReference[oaicite:1]{index=1}
- Запрос к edit endpoint — `multipart/form-data`. :contentReference[oaicite:2]{index=2}

### Реализация редактора маски (алгоритм)
1. Создать `maskCanvas` того же размера, что отображаемое изображение (лучше работать в “нативном” размере после ресайза).
2. Инициализировать маску: **залить белым непрозрачным**.
3. Режим “Удалять мебель”: рисовать **ластиком**, который делает пиксели **прозрачными**  
   - в canvas: `globalCompositeOperation = 'destination-out'`
4. Режим “Вернуть”: рисовать белым непрозрачным  
   - `globalCompositeOperation = 'source-over'`, цвет `#fff`
5. Экспорт: `maskCanvas.toBlob('image/png')` → отправить как `mask`.

## 7) Интеграция с OpenAI Images Edit (API)

### Endpoint
- `POST https://api.openai.com/v1/images/edits` :contentReference[oaicite:3]{index=3}

### Формат запроса (multipart/form-data)
Поля:
- `model`: `gpt-image-1.5` (дефолт) или `chatgpt-image-latest` :contentReference[oaicite:4]{index=4}
- `prompt`: строка
- `image[]`: исходное изображение (файл)
- `mask`: PNG маска (файл, alpha=0 в зонах удаления)
- Опционально:
  - `n=1`
  - `output_format=png|jpeg|webp` :contentReference[oaicite:5]{index=5}
  - `quality=high|medium` :contentReference[oaicite:6]{index=6}
  - `moderation=auto` :contentReference[oaicite:7]{index=7}

### Формат ответа
- Возвращается изображение в `data[0]...` (часто как base64) — сервер должен преобразовать в файл и отдать клиенту (или сохранить и вернуть URL). :contentReference[oaicite:8]{index=8}

> Важно: GPT Image модели могут требовать “organization verification” для использования. :contentReference[oaicite:9]{index=9}

## 8) Prompt (базовый шаблон)
Промпт должен требовать:
- удалить объекты именно в маске
- восстановить фон реалистично (пол/стены)
- **минимально менять вне маски**
- запретить добавление нового декора/текста/логотипов

**Base prompt (EN, использовать как есть):**
Remove all objects in the transparent masked area (furniture, clutter, personal items). Reconstruct the underlying room surfaces realistically (walls, floor, ceiling) with consistent perspective and lighting. Keep all non-masked areas as close to the original photo as possible. Photorealistic real-estate listing photo, clean empty room, no new furniture, no text, no logos.

## 9) Архитектура (рекомендуемая для MVP)
### Почему нужен сервер (обязательно)
Ключ OpenAI **нельзя** хранить на фронте — утечёт. Ключ должен быть только на сервере. (Общее правило безопасности ключей API.) :contentReference[oaicite:10]{index=10}

### Вариант A (рекомендуется): Next.js fullstack
- Frontend: Next.js pages/app
- Backend: `POST /api/declutter` (serverless)
- Хранение результата: 
  - MVP: вернуть файл сразу
  - Позже: S3/R2 + временные ссылки

### Вариант B: отдельно backend (Express/Fastify) + любой фронт
- Backend принимает `multipart/form-data` → вызывает OpenAI → отдаёт результат

## 10) Контракты API (между фронтом и твоим backend)

### POST /api/declutter
**Request:** `multipart/form-data`
- `image`: File (JPG/PNG)
- `mask`: File (PNG with alpha)
- (опционально) `output_format`: `png|jpeg|webp`
- (опционально) `quality`: `high|medium`

**Response (вариант 1):** `image/*` (бинарник)
- Content-Type: `image/png` (или jpeg/webp)

**Response (вариант 2):** JSON
- `{ "resultUrl": "https://..." }`

## 11) Валидации и ошибки
Backend должен проверять:
- наличие `image` и `mask`
- размер файлов (image ≤ 50MB, mask ≤ 4MB) :contentReference[oaicite:11]{index=11}
- mime types
- совпадение размеров image и mask (ширина/высота)
- rate limit per IP (например 10 запросов/мин)
- таймаут запроса в OpenAI (например 60–120 секунд)

UI ошибки:
- “Маска должна быть PNG с прозрачностью”
- “Маска должна совпадать по размеру с фото”
- “Слишком большой файл”
- “Сервис временно недоступен — попробуйте позже”

## 12) Нефункциональные требования (NFR)
- Время ответа MVP: целиться в 15–60 секунд на фото
- Надёжность: минимум 99% успешных ответов на валидных данных (зависит от внешнего API)
- Безопасность:
  - ключи только на сервере
  - CORS ограничить доменом фронта
  - basic rate limiting
- Логи:
  - request_id, время, размер входа, статус, текст ошибки (без хранения пользовательских фото в логах)

## 13) Порядок разработки (задачи для Codex)

### Milestone 1 — “Проверка идеи” (1 фото → результат)
1. Backend endpoint `/api/declutter`:
   - принимает multipart `image+mask`
   - дергает OpenAI `/v1/images/edits` :contentReference[oaicite:12]{index=12}
   - возвращает изображение
2. Простой фронт:
   - upload фото
   - upload готовой mask.png (пока вручную)
   - кнопка “Generate”
   - показать результат

**Acceptance критерий:** 10 реальных фото успешно обработаны.

### Milestone 2 — Рисование маски в браузере
1. Реализовать canvas-редактор маски по правилам из раздела 6
2. Экспорт mask.png и отправка вместе с image
3. Undo/Reset

**Acceptance критерий:** пользователь без фотошопа делает маску и получает результат.

### Milestone 3 — Полировка MVP
1. Валидации, сообщения об ошибках
2. Ресайз больших изображений на фронте (например max side 1600–2000 px)
3. Rate limiting
4. Мини-логирование

## 14) Definition of Done (DoD)
- Пользователь загружает фото → рисует маску → получает обработку → скачивает результат
- Маска экспортируется PNG с прозрачностью, совпадает по размеру с изображением
- API ключ OpenAI не утекает на фронт
- Есть понятные ошибки и защита от злоупотреблений
- Документация README: как запустить локально и как деплоить
