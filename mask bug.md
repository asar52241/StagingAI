# 🐞 Bug: Маска в ручном режиме сбрасывается при возврате к предыдущему фото

## 📌 Контекст

Фича: удаление объектов вручную (режим “кисть”)
Сценарий: обработка нескольких фотографий подряд в редакторе

---

## 🔁 Шаги воспроизведения

1. Загрузить несколько фотографий.
2. Выбрать режим **«Удаление вручную»**.
3. Открывается редактор с первым фото.
4. Нарисовать маску (отметить объекты для удаления).
5. Нажать **«Далее»** (перейти к следующему фото).
6. На втором фото ничего не делать (или сделать — не принципиально).
7. Нажать кнопку **«Назад»** (вернуться к первому фото).

---

## ❌ Фактический результат

* Маска на первом фото **визуально отсутствует**.
* Ранее выделенные области не отображаются.
* Пользователь не видит, что он уже разметил.

При этом:

* Судя по поведению системы, маска, вероятно, **сохраняется во внутреннем состоянии** и засчитывается при обработке.
* Проблема только в визуализации (UI не отображает сохранённую маску).

---

## ✅ Ожидаемый результат

* При возврате на предыдущее фото маска должна:

  * полностью отображаться
  * быть редактируемой (можно продолжить рисовать / стереть часть)
* Пользователь должен видеть текущий state разметки для каждого фото.

---

## 🎯 Влияние на пользователя

* Пользователь думает, что маска **сбросилась**.
* Теряется доверие к инструменту.
* Высокий риск повторной разметки (двойная работа).
* Потенциальные негативные отзывы и отказ от оплаты.

Это критично, потому что ручной режим — самый “контролируемый” сценарий, и пользователь ожидает точного сохранения состояния.

---

## 🧠 Предполагаемая причина (гипотеза)

Вероятно:

* Canvas / mask state хранится локально в компоненте.
* При переходе между фото компонент размонтируется.
* При возврате он монтируется заново без восстановления сохранённой mask state.
* Данные либо не сохраняются в общем состоянии (store), либо сохраняются, но не пробрасываются обратно в canvas.

---

## 🔧 Предложение по исправлению

1. Сохранять маску **для каждого фото отдельно** в общем состоянии (store / backend draft).
2. При загрузке фото в редактор:

   * проверять, есть ли сохранённая маска
   * если есть — рендерить её поверх изображения
3. Маска должна быть редактируемой, а не “плоским overlay”.
