## Требуется заполнить (TODO)

Откройте файл **`config/legal.ts`** и замените placeholder-значения:

| Поле | Placeholder | Что поставить |
|------|-------------|---------------|
| `sellerName` | `"Иванов Иван Иванович"` | ФИО полностью (как в паспорте) |
| `sellerInn` | `"000000000000"` | ИНН самозанятого (12 цифр) |
| `sellerCity` | `"Москва"` | Город ведения деятельности |
| `email` | `"support@staging-ai.ru"` | Рабочий email поддержки |
| `phone` | `"+7 (000) 000-00-00"` | Телефон (или уберите поле) |
| `telegram` | `"@stagingai"` | Telegram-псевдоним (или уберите поле) |
| `siteUrl` | `"https://staging-ai.ru"` | Реальный домен; или задайте `NEXT_PUBLIC_SITE_URL` в `.env.local` |
| `docsUpdatedAt` | `"27.02.2025"` | Обновите при изменении документов |
