# Data Minimization — StagingAI

## Что мы НЕ собираем

| Данные | Статус |
|---|---|
| ФИО пользователя | Не запрашивается |
| Email / телефон | Не запрашивается |
| Аккаунты / профили | Отсутствуют |
| Cookies аналитики | Не используются |
| Поведенческие метрики | Не собираются |

## Изображения пользователей

- Загруженные фотографии **не записываются на диск** и **не сохраняются в storage**.
- Обработка выполняется «на лету»: изображение принимается в память сервера, передаётся транзитом во внешний сервис обработки, результат сразу возвращается клиенту.
- После завершения HTTP-ответа данные изображения освобождаются из памяти.
- Никаких временных файлов в `/tmp` или иных директориях не создаётся.

## Учёт оплаченных заказов

Для контроля оплаченного количества фото сервер хранит запись заказа: номер счёта Робокассы (`invId`), число оплаченных и уже обработанных фото, дату создания. Запись не связана с личностью — ни ФИО, ни email, ни телефон в ней не участвуют, срок хранения ограничен (48 часов). Это единственные данные, которые сервис хранит постоянно.

## Rate-limit на создание платежа

Чтобы ограничить спам неоплаченными счетами, при создании платежа IP-адрес хэшируется (SHA-256, необратимо) и на несколько минут сохраняется счётчик запросов с этим хэшем. Это транзитное состояние против злоупотреблений, не накопительная база данных — запись автоматически исчезает по истечении окна.

## Что попадает в технические логи

Журналы хостинга (Vercel Runtime Logs) могут содержать:

| Поле | Примечание |
|---|---|
| `request_id` | UUID запроса (для диагностики) |
| `ip` | IP-адрес клиента |
| `duration_ms` | Время выполнения запроса |
| `status` | HTTP-статус ответа |
| `code` | Внутренний код результата |
| `mode` | Режим обработки (`mask` / `auto`) |
| `image_bytes` | Размер файла в байтах (не содержимое) |
| `image_width`, `image_height` | Разрешение изображения |
| `output_format`, `quality` | Параметры вывода |

**Не логируются:** содержимое изображений, тело запроса, IP в обезличенной форме не хранится отдельно.

Хранение журналов ограничено политикой хостинг-провайдера.

## Cache-Control

API-маршрут `/api/declutter` возвращает заголовок `Cache-Control: no-store`, запрещая кеширование результатов промежуточными узлами.

## Рекомендации пользователям

Не загружайте изображения, содержащие людей, документы, госномера, адреса и иную идентифицирующую информацию. Сервис предназначен для обработки фотографий помещений.
